# 5. Classification legend

- **PASS / CLOSED** — verified and closed within the explicitly declared scope.
- **PASS / LOCAL** — verified for a finite/tested set; not a general theorem.
- **FAIL / CLOSED** — proposed route or claim is disproved/invalid and must not be reused.
- **OPEN** — unresolved research question.
- **OPEN / LOAD-BEARING** — unresolved and currently blocking the intended structural theorem.
- **CONDITIONAL** — valid only after an explicitly stated additional hypothesis/bridge.
- **HISTORICAL / SUPERSEDED** — retained for provenance but no longer controls the current direction.
