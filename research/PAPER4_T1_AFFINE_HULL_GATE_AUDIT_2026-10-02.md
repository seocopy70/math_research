# PAPER 4 — T1 AFFINE-HULL GATE: SEPARATED MULTI-SINK COUNTEREXAMPLE — 2026-10-02

## Decision

The affine-hull theorem is **refuted for the current T1 local-uniform signature**.

The smallest decisive model is the separated two-sink graph
\[
G=\langle a,b,s,t\mid sas^{-1}=a^{1+q},\;tbt^{-1}=b^{1+q}\rangle,
\]
with no other edges, where \(q=p^f\) and \(p\) is odd.

Let
\[
O=\operatorname{span}(\bar a,\bar b),\qquad
U=L_1/O=\operatorname{span}(\bar s,\bar t).
\]
The canonical normalization is
\[
\omega_q(\bar s)=\omega_q(\bar t)=1.
\]

Consider
\[
u=\bar s+\bar t.
\]
Although \(u\) is not a vertex direction and
\[
\omega_q(u)=2\ne1
\]
(for \(p\ne2\)), it passes the current existential local special-edge signature.

Indeed, using the origin \(a\), one has \([t,a]=1\), hence
\[
(s t)a(s t)^{-1}=s a s^{-1}=a^{1+q}.
\]
Therefore the subgroup generated by \(st\) and \(a\) has exactly the same special-edge semidirect relation as the 2-generator control. At the first q-defect layer,
\[
B_q(u,\bar a)=\overline{a^q}=P_E(\bar a).
\]
Thus \(u\in\mathcal S_E\) under the present definition: it has a finite special-edge local signature normalized by the intrinsic q-power target.

But \(u\) lies outside the desired affine hyperplane
\[
\omega_q^{-1}(1)
=\{\alpha\bar s+\beta\bar t:\alpha+\beta=1\}.
\]

Since \(\bar s,\bar t\in\mathcal S_E\) as the genuine sink directions and \(\bar s+\bar t\in\mathcal S_E\), the three points are not collinear:
\[
\bar s,\bar t\in\omega_q^{-1}(1),
\qquad
\bar s+\bar t\notin\omega_q^{-1}(1).
\]
Because \(\dim U=2\),
\[
\operatorname{Aff}(\mathcal S_E)=U,
\]
so its affine codimension is 0, not 1.

For \(p=3\), this is especially sharp:
\[
\omega_q(\bar s+\bar t)=2\ne1.
\]
More generally, any prime \(p>2\) gives the same obstruction.

## Why this is structural, not an isolated accident

The mechanism is not tied to the particular vector \(s+t\). If a sink \(t\) is invisible to the chosen origin \(a\), then multiplying the local special generator \(s\) by an arbitrary commuting sink component does not change the 2-generator relation with \(a\).

Thus the existential local signature sees the **local projection of a direction onto one incidence component**, whereas \(\omega_q\) is the **global sum of all sink coordinates**.

In the separated graph, the local signature cannot distinguish
\[
s
\quad\text{from}\quad
s+t
\]
when tested against \(a\). The intrinsic q-power normalization fixes the coefficient seen by \(a\), but it does not constrain the invisible \(t\)-component.

This is exactly the failure mode that the affine-hull question was intended to detect.

## Consequence for the affine-hull strategy

The implication
\[
\mathcal S_E\subseteq\omega_q^{-1}(1)
\]
is false for the current definition.

Therefore the hoped-for chain
\[
\mathcal S_E
\Longrightarrow
\operatorname{Aff}(\mathcal S_E)=\omega_q^{-1}(1)
\Longrightarrow
\omega_q
\]
cannot be used.

The failure occurs before any filtered-isomorphism/naturality issue. It is already a local-model separation failure.

## Important distinction from the overlapping model

The overlapping model
\[
sas^{-1}=a^{1+q},\qquad tat^{-1}=a^{1+q}
\]
had the accidental direction
\[
\frac12(\bar s+\bar t)
\]
which satisfies \(\omega_q=1\). That example therefore did not refute the affine-hyperplane claim.

The separated model is stronger: it produces an admissible accidental direction with \(\omega_q\ne1\).

## Can the definition be repaired?

Only by strengthening the signature so that it constrains all relevant sink components, not merely the existence of one special-edge 2-generator witness.

But that is not a harmless refinement.

- A global rank-one condition is already known to be incompatible with the complete one-sink model, where \(B_q(s,-)\) has rank equal to the number of independent origins.
- Requiring a direction to be tested against every incident origin effectively reintroduces graph-incidence information, moving away from the target-first minimal normalization problem.
- Requiring the signature to be globally normalized by \(\omega_q\) would be circular.

Hence the present failure is not repaired by a cosmetic change of wording.
