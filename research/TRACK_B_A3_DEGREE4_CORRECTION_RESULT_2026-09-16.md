# Track B — A3-3: Degree-4 correction result

Date: 2026-09-16

## 1. Input

From A3-2, after removing the degree-2 class from
\(C(x_1)=x_2x_1x_2^{-1}\), we obtained an element \(s\in D_3\) with
\[
\operatorname{in}_3(s)
=X_1^{[3]}+2[[X_3,X_4],X_1]+2[[X_3,X_4],X_2].
\]

The purpose of A3-3 is to determine the degree-4 class induced by bracketing this degree-3 class with \(X_1\), and to locate it in
\[
Q_4=L_4/(R)_4,
\qquad W=\langle Sp_4(\mathbb F_3)\cdot T\rangle.
\]

## 2. Exact graded calculation

Because \(X_1^{[3]}\) is the restricted p-power of \(X_1\),
\[
[X_1^{[3]},X_1]=0.
\]
Therefore only the Lie correction contributes:
\[
\begin{aligned}
[\operatorname{in}_3(s),X_1]
&=2[[[X_3,X_4],X_1],X_1]
 +2[[[X_3,X_4],X_2],X_1].
\end{aligned}
\]

Writing
\[
T=[[[X_3,X_4],X_1],X_1],
\]
this is
\[
\boxed{
2T+2[[[X_3,X_4],X_2],X_1].
}
\]

## 3. Exact finite-field certificate

The authoritative Phase 2-1 construction was reused without alteration. It gives
\[
\dim (R)_4=5,
\qquad \dim W=45,
\qquad \operatorname{rank}[(R)_4+W]=50.
\]

For the A3-3 degree-4 vector \(d_4=[\operatorname{in}_3(s),X_1]\), exact Gaussian elimination over \(\mathbb F_3\) gives:
\[
\operatorname{rank}[(R)_4+W+d_4]=50,
\]
so
\[
\boxed{d_4\in W}.
\]

On the other hand,
\[
\operatorname{rank}[(R)_4+d_4]=6,
\]
so
\[
\boxed{d_4\notin(R)_4},
\]
and hence
\[
\boxed{d_4\neq0\text{ in }Q_4}.
\]

Thus the degree-4 correction is simultaneously:

- nonzero in the degree-4 quotient \(Q_4\);
- entirely contained in the previously identified 45-dimensional module \(W\).

## 4. Jacobson correction issue

This calculation does not identify the Lie correction with a new restricted p-power term. The term
\[
2[[X_3,X_4],X_1]+2[[X_3,X_4],X_2]
\]
is an ordinary Lie-bracket correction in the degree-3 class.

The A3-3 operation used here is the bracket with \(X_1\), and the restricted p-power part drops out because
\[
[X_1^{[3]},X_1]=0.
\]

Therefore the degree-4 signal obtained here is not being attributed to a naive linearization of the Jacobson p-power map.

## 5. Interpretation

This is an important narrowing of the problem.

The A3 correction does reach degree 4, and it does so inside the same \(W_{45}\) already generated by the quadratic-shadow obstruction \(T\). In particular, A3 does **not** produce a new degree-4 component outside \(W\) at this stage.

This does not yet show that orientation information is lost. It only shows that this specific A3 degree-3 correction, after one further graded bracket, lands nontrivially inside the existing 45-dimensional structure.
