# A3-4-18 — B/A vs K: socle / radical / Loewy analysis

## Objective

A3-4-17 established, in the exact A3-4-16 action-matrix setting,

\[
\dim \operatorname{Hom}_H(B/A,K)=1,
\qquad
\max \operatorname{rank}(P)=10<35,
\]

hence

\[
B/A\not\cong_H K.
\]

A3-4-18 now asks where the module structures differ at the level of submodule
and extension structure.

## Representation source

The calculation imports
`A3-4-16_STRONG_MODULAR_FINGERPRINT_2026-09-16.py`, so the five 35x35
matrices for B/A and K are exactly the same matrices used by A3-4-16 and
A3-4-17. No new coordinate construction is introduced.

## Exact computational method

GAP's MeatAxe is used over \(\mathbb F_3\). MeatAxe is specifically designed
for finite-dimensional modules and provides exact routines for minimal
submodules, radical, socle, composition factors, and induced submodule/factor
actions.

The existing matrices act on column vectors on the left. GAP MeatAxe uses row
vectors on the right, so every generator is transposed before constructing the
GAP module. This is only a convention change, not a new representation.

For each module we compute:

1. `MTX.BasisSocle(M)` — exact socle and its dimension.
2. `MTX.BasisRadical(M)` — exact radical and its dimension.
3. Successive induced submodules by the radical to obtain
   \(M\supset\operatorname{rad}M\supset\operatorname{rad}^2M\supset\cdots\).
4. Successive factor modules by the socle to obtain the socle filtration.
5. Composition-factor dimensions and collected multiplicities.
6. Indecomposability.

The radical/socle routines are not replaced by the weaker quantities
\(\sum_g (g-1)M\) or \(M^H\); those would not in general equal the radical or
socle for a non-p-group such as \(Sp_4(\mathbb F_3)\).

## Interpretation protocol

- If socle dimensions differ, this is an immediate module-structure
  distinction.
- If radical dimensions differ, likewise.
- If radical filtration dimensions differ, the Loewy structure differs even
  when first radical dimensions agree.
- If socle filtration dimensions differ, the dual Loewy structure differs.
- Equal Loewy dimensions do **not** prove isomorphism; they only show that the
  difference is subtler than these numerical Loewy invariants.
- Composition-factor dimensions alone are not treated as module-isomorphism
  evidence.
