# HARD ATTACK 15 — MOD-27 CATEGORY ADEQUACY / TRIVIAL-INTRINSICITY LOOP — 2026-09-20

## Target

Before constructing any higher obstruction, attack the admissible input category itself. The current PRE-MOD27 gate allows the group G together with an allowed filtered relation datum. If “G” is allowed without restriction, then the canonical dualizing module and canonical orientation are already intrinsic group invariants. This creates a trivial J_27 and would make the carrier question ill-posed unless the admissible input is narrowed.

## 1. Trivial intrinsic carrier exists at the unrestricted-group level

For an infinite Demuškin pro-3 group G, the canonical orientation is the action of G on its dualizing module. The literature also characterizes it via the unique 1-cyclotomic/Kummerian orientation. Thus the object “dualizing module modulo 27 together with its G-action” already contains chi mod 27.

Likewise, the full isomorphism class of G determines the Demuškin invariant q and rank, and the classification theorem then recovers the canonical orientation. This is intrinsic but tautological relative to the intended filtered/relation-data problem.

Decision: unrestricted group-only J_27 is **HISTORICAL / SUPERSEDED as a carrier candidate**, not evidence for the intended research problem.

## 2. The PRE-MOD27 gate therefore needs a sharper input restriction

“q-blind” cannot mean only “q is not literally supplied.” If the full group G is an allowed input and arbitrary intrinsic constructions are allowed, one may first extract q or the dualizing action and then package it as J_27.

The intended admissible input must therefore be a declared filtered/relation-information functor that does not already include the dualizing module/action or an equivalent complete classification invariant.

The revised q-blindness/non-tautology condition should exclude:

- explicit chi or its finite reductions;
- the dualizing-module action used as the target;
- q or an equivalent complete Demuškin classification invariant when used merely to reconstruct chi by the known classification formula;
- any functor from the input to the target that factors through an already-known canonical-orientation object without an independent obstruction construction.

## 3. Consequence for candidate mechanisms

A higher Bockstein, higher A-infinity/Hochschild class, or filtered relation extension is admissible only if its construction uses the declared filtered/relation data directly and does not first recover the dualizing action/q and then repackage it.

In particular, “recover q from abelianization, then insert q into chi(x_2)=(1-q)^(-1)” is a valid group-classification calculation but is not a new J_27 carrier for this project.

## 4. Stronger positive/negative boundary

The mod-27 problem is now split cleanly:

(A) **Unrestricted group-intrinsic reconstruction:** trivial/known from the canonical dualizing structure; no new carrier claim.

(B) **Filtered/relation-data reconstruction:** still open. The input must retain genuine extension information but not the target itself.

(C) **Associated-graded/cohomological mod-3 data only:** already insufficient for full orientation; the complete graded object is q-blind.

(D) **Exact filtered extension tower:** sufficient by inverse limit + Fox, but essentially retains the completed relation and is not a compression result.

The only mathematically substantive remaining question is therefore (B): whether there is an independently defined finite-level mod-27 extension carrier, with a natural reduction to the audited J_9, that is not merely the exact Fox relation or a disguised classification/dualizing invariant.

## 5. Literature cross-check

Published Demuškin classification identifies the canonical orientation and q as intrinsic invariants, while the canonical orientation is also described through the dualizing module. This confirms that the unrestricted-group loophole is real and must be excluded by the input category rather than treated as a discovery.

## Decision

**CATEGORY-ADEQUACY CORRECTION: PASS / CLOSED.**

The correction does not close or prove existence of J_27. It closes a methodological loophole: the PRE-MOD27 gate must distinguish “intrinsic because it is a functor of G” from “intrinsic filtered/relation carrier that does not already contain the orientation.”

Next authorized target: after revising the gate, test only genuinely filtered/relation/cohomological extension constructions for a mod-27 carrier. No numerical scan is authorized until the revised input category is frozen.
