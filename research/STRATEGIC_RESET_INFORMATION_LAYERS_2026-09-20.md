# STRATEGIC RESET 2026-09-20 — FROM LOCAL CLOSURES TO INFORMATION-LAYER THEOREM

## Purpose

After Hard Attacks 48–56, the project has accumulated several rigorous local boundaries. The present strategic question is whether continuing to close individual candidates (actual automorphism image, Q_2 lift, 19D module, twisted beta^2) is still the highest-value path.

## Critical assessment

The answer is: **not by default**. The local attacks remain mathematically legitimate, but the research risk is now a search tree with many branches whose common parent is still unresolved:

> What is the minimum *kind* of non-graded information required to distinguish the canonical orientation, and how does that information propagate through the filtration tower?

The established results already support a stronger layer-level organization.

### Layer A — full mod-3 associated graded

Closed as q-blind for the rank-4 Demuškin family. It cannot recover the Z_3-valued orientation.

### Layer B — first extension / relation-jet data

The intrinsic projective degree-(2,3) carrier \([(R,p)]\) is sufficient for \(\chi\bmod 9\), under the stated transgression/Bockstein hypotheses. This is a genuine positive result, not merely a failed-candidate boundary.

### Layer C — deeper finite extension/cohomology

The 19-dimensional permanent LHS piece of \(H^3(Q_2,F_3)\) exists at frozen q=3, but its orientation role is unresolved. The full ambient Sp_4 action has now been shown not to be the actual automorphism symmetry because of the intrinsic torsion line. Therefore the 19D representation branch should not be allowed to become the new center of gravity unless a precise structural reason connects it to the orientation selector.

## Strategic conclusion

The next high-value task is **not** “compute the 19D module at all costs.” It is to formulate and test an information-layer theorem of the form:

1. characterize exactly what Layer A cannot see;
2. characterize the minimal Layer B datum needed for the first orientation digit;
3. determine whether higher digits require genuinely new extension classes or are generated functorially from the same relation-jet tower;
4. formulate a no-go/adequacy criterion for any Layer C candidate before computing its full module structure.

This converts many local attacks into one structural program.

## Concrete immediate tests

### Test I — digit-depth equivalence

For the standard family \(G_{3^s}\) versus the power-free control, compare the least filtration depth at which the finite object separates \(\chi\bmod 3^n\). The project already has a local sharp Zassenhaus threshold, but this should be reformulated as an explicit information-depth theorem rather than a collection of quotient coincidences.

### Test II — tower reuse

Ask whether the mod-9 carrier \([(R,p)]\) admits a canonical higher congruence lift whose successive obstruction maps are functorially determined from the same relation/power tower. If yes, this would be a structural explanation of how infinitely many digits arise without requiring an independent finite carrier at each digit. If no, identify the first genuinely new layer.

### Test III — C candidate gate

For any proposed finite extension/cohomology carrier (including the 19D \(\mathcal S\)), require before representation computation:

- q-blind definition;
- intrinsic functoriality;
- an explicit map to the twisted orientation obstruction;
- proof that it contains information not already generated by Layer B;
- a separation test on q=3 versus the power-free control.

If one of these fails, close the candidate without computing its full module structure.

## What remains of the short-term HA56 branch

The actual automorphism image remains a legitimate load-bearing question, but it is now subordinate to the layer theorem. It should be pursued only if it supplies an essential functoriality mechanism for a candidate carrier. Otherwise it is a side branch.

## New strategic classification

- Layer A q-blindness: **PASS / CLOSED**.
- Layer B mod-9 intrinsic recognition: **PASS / CLOSED**.
- Sharp filtration-depth boundary for finite recognition: **PASS / LOCAL** until stated as a general theorem.
- Higher-digit reuse of the Layer B tower: **OPEN / DECISIVE**.
- Any specific Layer C carrier, including the 19D \(\mathcal S\): **OPEN / CONDITIONAL on adequacy test**.
- Full PD^2-free intrinsic carrier for all digits: **OPEN / DECISIVE**.

## Stop rule

No new representation scan, no broad spectral scan, and no full 19D module computation is authorized until Test I or Test II yields a concrete structural target.

The project therefore shifts temporarily from **candidate elimination** to **information architecture**.
