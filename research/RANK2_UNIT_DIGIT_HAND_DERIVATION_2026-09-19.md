## 1. Relation module and relator unit

Let F be the free pro-3 group on x1,x2, R the closed normal subgroup generated by
r_q=x1^q[x1,x2].

For the one-relator presentation, the relation module
M=R/[R,F]
is a free rank-one Z_3-module once the relator class [r_q] is chosen as generator.

For an actual phi in Aut(G_q), a free lift \tilde phi preserving R induces an automorphism of (M=R/[R,F]). If (M) is indeed free rank one with generator ([r_q]), this action has the form
\[
\tilde\phi([r_q])=u_{\tilde\phi}[r_q],\qquad u_{\tilde\phi}\in\mathbf Z_3^\times.
\]
At this point (u_{\tilde\phi}) is a scalar attached to the **chosen lift**. Lift-independence is a separate theorem and is not established here. Two lifts differ by an element of (\ker(\operatorname{Stab}(R)\to\operatorname{Aut}(G_q))), and the action of that kernel on (R/[R,F]) must be computed or proved trivial before (u(\phi)) can be defined intrinsically.

## 2. Multiplicativity

For fixed free lifts whose compositions are again the chosen lifts, the scalar is multiplicative by functoriality of the induced action on (M). However, until lift-independence is proved, this gives a multiplicative law for the **lift-level scalar** (u_{\tilde\phi}), not yet a well-defined character on (\operatorname{Aut}(G_q)).

This also means the first 3-adic digit of u is a multiplicative character. The additive digit on 1+3Z_3 is obtained only after proving u mod 3=1 on the relevant subgroup.

## 3. q=infinity control

For q=infinity,

G_infinity^(2)=<x1,x2 | [x1,x2]>=Z_3^2.

An integral automorphism A in GL_2(Z_3) sends the basic commutator to

[x1,x2]^{det A}

in the relation module (with the chosen commutator convention).

Hence

u_infinity(phi)=det(A)

for the natural integral presentation convention.

Therefore u mod 9 is already visible from the integral linear action in the abelian case. This is a control, not yet a filtered-observability theorem.

## 4. q=3: orientation constraint derived, but u mod 9 is NOT yet derived

For

r_3=x1^3[x1,x2],

the canonical Demushkin orientation, derived by requiring arbitrary chi-crossed derivations to kill r_3, has

chi(x1)=1,
chi(x2)=(1-3)^(-1)=(-2)^(-1).

This agrees with the standard odd-prime Demushkin orientation pattern; literature confirms the existence/functoriality of the canonical orientation, but the exact equality u=chi for the relator module remains unproved here.

Since every automorphism preserves the canonical orientation, write the abelianized action as

phi(x1)_ab = x1^a x2^(3c),
phi(x2)_ab = x1^b x2^d.

Applying chi gives

(-2)^(-3c)=1,

so c=0, and

(-2)^(-d)=(-2)^(-1),

so d=1.

Thus the abelianized automorphism has the form

[[a,b],[0,1]]

with a in (Z/3Z)^times.

The degree-2 cup-product preservation then forces the mod-3 determinant to be 1, hence a=1 mod 3. Consequently the induced mod-3 matrix of an actual automorphism is of the form

g = [[1,b],[0,1]]

rather than an arbitrary GL_2(F_3) matrix.

In particular the tested q=3 exclusion of -I is structurally consistent with this constraint.

## 8. Critical structural correction — q=3 relation module is not rank-one

The kernel analysis exposes a more fundamental issue. The earlier claim that (M=R/[R,F]) is rank-one for q=3 is not justified by the one-relator presentation. The standard five-term/Hopf sequence gives
\[
H_2(G,\mathbf Z_3)\to R/[R,F]\to F_{ab}\to G_{ab}\to0.
\]
For q=3,
\[
F_{ab}\cong\mathbf Z_3^2,qquad G_{3,ab}\cong\mathbf Z_3\oplus\mathbf Z/3,
\]
so the image of (R/[R,F]) contains the rank-one kernel generated by the abelianized relation (3e_1). Since an infinite Demushkin group has (H_2(G,\mathbf Z_3)cong\mathbf Z_3) by Poincare duality, the relation module cannot simply be identified with a single (mathbf Z_3[r_3]) line.

Consequently
\[
\tilde\phi([r_3])=u_{\tilde\phi}[r_3]
\]
is not an automatic scalar-action statement. An additional (H_2)-component can occur, and extracting a scalar requires an extra quotient/projection whose intrinsicity must itself be proved.

For q=infinity, (G=\mathbf Z_3^2), the abelianization map has zero kernel and (H_2(G,\mathbf Z_3)\cong\mathbf Z_3), so the rank-one control is compatible there. Thus the q=3/q=infinity relation-module structures already differ before any mod-9 digit is defined.

**Consequence:** the current relator-unit scalar definition is structurally unclosed for q=3. The prior D1/D3 statements must not be used. No mod-9, IA, or lift scan is authorized. The next task is definition-level analysis of the exact sequence and any canonical quotient that could support a scalar.

## 2026-09-19 — Critical correction: relation-module rank-one objection withdrawn

Thus for r_3=x_1^3[x_1,x_2], the map R/[R,F] -> F_ab sends a chosen generator to 3e_1 and is injective.
