# PAPER 3 — INTRINSIC SELECTOR-WINDOW MINIMALITY — 2026-09-28

## Status

**PASS / CLOSED for the fixed rank-4, q=3 pro-3 Demuškin group, all k>=2.**

Let
\[
N=p^{k-1}=3^{k-1},\qquad W_m=G/D_m(G).
\]
The established recognition theorem works at
\[
W_{N+1}.
\]
We now prove that no \(W_m\) with \(m\le N\) can work.

## 1. Canonical orientation

For
\[
G=\langle x_1,x_2,x_3,x_4\mid x_1^3[x_1,x_2][x_3,x_4]=1\rangle,
\]
Labute's canonical orientation satisfies
\[
\chi(x_2)=(1-3)^{-1},\qquad \chi(x_i)=1\;(i\ne2).
\]
Thus
\[
u:=\chi_k(x_2)=(1-3)^{-1}\pmod{3^k}
\]
has exact order
\[
N=3^{k-1}.
\]
The abelianization has a free \(\mathbf Z_3\)-direction generated by \(x_2\). citeturn8search25turn8search24turn7search0

For an abelian pro-p group, the Zassenhaus filtration is the power filtration
\[
D_m(A)=A^{p^{\lceil\log_p m\rceil}},
\]
by the Jennings–Lazard formula. citeturn9search0

## 2. Very shallow windows: \(m\le p^{k-2}\)

If
\[
m\le p^{k-2},
\]
then
\[
\lceil\log_p m\rceil\le k-2.
\]
Hence the image of \(D_m(G)\) in the free abelian \(x_2\)-direction contains
\[
x_2^{p^{\lceil\log_p m\rceil}},
\]
whose \(\chi_k\)-value is nontrivial modulo \(p^k\), because \(\chi_k(x_2)\) has order \(p^{k-1}\).

Therefore
\[
\boxed{
m\le p^{k-2}
\Longrightarrow
\chi_k\text{ does not factor through }W_m.
}
\]

Such a quotient cannot possibly be a finite recognition input for \(\chi_k\): the canonical candidate is not even defined on it.

## 3. The final block: \(p^{k-2}<m\le N\)

Now
\[
p^{k-2}<m\le p^{k-1}
\]
implies
\[
\lceil\log_p m\rceil=k-1.
\]
Thus the image of \(x_2\) in the abelianization of \(W_m\) has exact order
\[
N=p^{k-1}.
\]
Also
\[
D_m(U_{1,k})=1,
\]
so \(\chi_k\) factors through every such \(W_m\).

Therefore factorization alone does not exclude this whole block.

We now show that the Kummer predicate itself fails.

## 4. Endpoint-block obstruction

Because the image of \(x_2\) has order \(N\), there exists
\[
f\in H^1(W_m,\mathbf F_p)
\]
with
\[
f(x_2)=1.
\]

Suppose that \(f\) lifts to
\[
z\in Z^1(W_m,A_k(\chi_k)).
\]
Since \(x_2^N=1\) in \(W_m\),
\[
0=z(x_2^N)
=
S_N(u)z(x_2),
\]
where
\[
S_N(u)=1+u+\cdots+u^{N-1}
=\frac{u^N-1}{u-1}.
\]

For \(u=(1-p)^{-1}\), LTE gives
\[
v_p(u^N-1)
=
v_p((1-p)^N-1)
=
v_p(N)+1
=
k.
\]
Also
\[
v_p(u-1)=1.
\]
Hence
\[
\boxed{v_p(S_N(u))=k-1.}
\]

Therefore
\[
S_N(u)z(x_2)=0\pmod{p^k}
\]
forces
\[
p\mid z(x_2).
\]
But then
\[
z(x_2)\equiv0\pmod p,
\]
contradicting
\[
f(x_2)=1.
\]

Thus
\[
\boxed{
\mathsf K_k(W_m,\chi_k)\text{ fails for every }
p^{k-2}<m\le p^{k-1}.
}
\]

This includes the boundary quotient \(W_N\).

## 5. Sharp selector-window theorem

We have exhausted all \(m\le N\):

- if \(m\le p^{k-2}\), \(\chi_k\) does not factor through \(W_m\);
- if \(p^{k-2}<m\le p^{k-1}\), \(\chi_k\) factors, but \(\mathsf K_k(W_m,\chi_k)\) is false.

Since recognition is already proved at \(W_{N+1}\), we conclude

\[
\boxed{
n_{\mathrm{selector}}(k)=p^{k-1}+1=3^{k-1}+1
}
\]

for the fixed rank-4, \(q=3\), pro-3 Demuškin group.

This is **absolute minimality within the stated Zassenhaus finite-window selector architecture**, not merely affine-category sharpness.

## 6. Why this is stronger than the affine sharpness theorem

The affine theorem showed that some twisted crossed cocycles remain nontrivial on \(D_N\), so the full affine lifting category cannot factor through a shallower quotient.

That alone did not prove selector minimality.

The new argument is independent:

\[
D_N\text{ is exactly the layer at which }
\begin{cases}
\chi_k\text{ becomes factorizable},\\
\text{but the canonical Kummer lifting condition is still impossible}.
\end{cases}
\]

The obstruction is already visible on the single cyclic relation
\[
x_2^{p^{k-1}}=1
\]
in the quotient.

Thus the \(+1\) is intrinsic to the finite Kummer selector itself.

## 7. Extension in q

For a standard odd-p Demuškin group with
\[
q=p^f
\]
and \(f<k\),
\[
\chi(x_2)=(1-p^f)^{-1}.
\]
The same computation gives
\[
v_p\left(
\frac{\chi(x_2)^{p^{k-1}}-1}
{\chi(x_2)-1}
\right)=k-1,
\]
so the endpoint-block obstruction persists.

If \(f\ge k\), the canonical orientation is trivial modulo \(p^k\), so this particular proof does not establish uniform minimality. The fixed project theorem remains the \(p=q=3\) case.
