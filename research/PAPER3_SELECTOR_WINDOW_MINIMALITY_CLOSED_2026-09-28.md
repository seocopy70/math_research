# PAPER 3 — INTRINSIC SELECTOR-WINDOW MINIMALITY — 2026-09-28

## Status

**PASS / CLOSED for the fixed rank-4, q=3 pro-3 Demuškin group, all k>=2.**

The absolute intrinsic selector-window minimality has now been proved.

The sharp window
\[
W_{p^{k-1}+1}(G)
\]
is not merely sufficient: no shallower Zassenhaus quotient can serve as the finite Kummer selector input.

The proof has two parts:
1. for every \(m<p^{k-1}\), the canonical orientation \(\chi_k\) does not even factor through \(W_m\);
2. at the endpoint \(m=p^{k-1}\), \(\chi_k\) does factor, but the finite Kummer predicate already fails for \(\chi_k\) itself.

Thus the next quotient \(W_{p^{k-1}+1}\) is genuinely necessary.

## 1. Setup

Fix
\[
p=3,\qquad q=3,
\]
and let
\[
A_k=\mathbf Z/3^k\mathbf Z,
\qquad
\chi_k:G\to U_{1,k}=1+3A_k
\]
be the canonical orientation modulo \(3^k\).

Put
\[
N=p^{k-1}=3^{k-1},
\qquad
W_m=G/D_m(G).
\]

The established finite-window theorem uses
\[
W_{N+1}.
\]

We prove that every \(m\le N\) is insufficient.

## 2. The canonical orientation on the abelian direction

In the standard Demuškin presentation
\[
r=x_1^3[x_1,x_2][x_3,x_4],
\]
the canonical orientation satisfies
\[
\chi(x_2)=(1-3)^{-1},
\qquad
\chi(x_i)=1\quad(i\ne2).
\]
This is the classical Labute formula. citeturn8search25turn8search24

In particular
\[
u:=\chi_k(x_2)=(1-3)^{-1}\pmod{3^k}
\]
has exact order \(3^{k-1}=N\) in \(U_{1,k}\).

Also, the abelianization of a Demuškin group has a free \(\mathbf Z_p\)-direction generated by the image of \(x_2\):
\[
G_{\mathrm{ab}}\simeq \mathbf Z_p^{3}\oplus\mathbf Z/3\mathbf Z
\]
in the present rank-four, \(q=3\) case. citeturn7search0

For the Zassenhaus filtration, the image in an abelian pro-p quotient is the usual power filtration
\[
D_m(G_{\mathrm{ab}})
=
G_{\mathrm{ab}}^{,p^{\lceil\log_p m\rceil}}.
\]
This follows directly from the Jennings–Lazard description
\[
D_m=\prod_{ip^j\ge m}\gamma_i^{p^j};
\]
for an abelian group only \(i=1\) remains. citeturn9search0

Therefore, if \(m<N=p^{k-1}\), the image of \(x_2\) in \(W_m\) still has order at least \(p^{\lceil\log_p m\rceil}\), while \(\chi_k\) has full order \(p^{k-1}\) on that direction. More directly, \(\chi_k(D_m(G))\ne1\) because the image of \(D_m(G)\) in the free abelian \(x_2\)-direction contains \(x_2^{p^{\lceil\log_p m\rceil}}\), whose \(\chi_k\)-value is nontrivial when \(\lceil\log_p m\rceil<k-1\).

Hence:

\[
\boxed{
m<N\quad\Longrightarrow\quad
\chi_k\text{ does not factor through }W_m.
}
\]

So every strictly shallower quotient is already impossible as a recognition input: the canonical target character is absent from the candidate space.

## 3. The endpoint \(m=N\) is subtler

At
\[
m=N=p^{k-1},
\]
the target principal-unit group has reached its final Zassenhaus layer:
\[
D_N(U_{1,k})=1.
\]

Therefore \(\chi_k\) **does** factor through
\[
W_N=G/D_N(G).
\]

So factorization alone cannot exclude \(W_N\).

We now show that the finite Kummer predicate fails even for the canonical candidate.

## 4. A mod-p class that cannot lift on W_N

The image of \(x_2\) in the free abelian quotient has exact order \(N\) modulo \(D_N\). Hence there is a class
\[
f\in H^1(W_N,\mathbf F_p)
\]
with
\[
f(x_2)=1.
\]

Suppose, for contradiction, that \(f\) has a lift
\[
z\in Z^1(W_N,A_k(\chi_k)).
\]

Write
\[
u=\chi_k(x_2)=(1-p)^{-1}\pmod{p^k},
\qquad p=3.
\]

Since \(x_2^N=1\) in \(W_N\), the crossed-cocycle power formula gives
\[
0=z(x_2^N)
=
(1+u+\cdots+u^{N-1})z(x_2).
\]

Set
\[
S_N(u)=1+u+\cdots+u^{N-1}
=
\frac{u^N-1}{u-1}.
\]

By LTE,
\[
v_p(u^N-1)
=
v_p\bigl((1-p)^{-N}-1\bigr)
=
v_p\bigl((1-p)^N-1\bigr)
=
v_p(N)+v_p(p)
=
(k-1)+1=k.
\]

Since
\[
v_p(u-1)=1,
\]
we obtain
\[
\boxed{v_p(S_N(u))=k-1.}
\]

Therefore
\[
S_N(u)z(x_2)=0\pmod{p^k}
\]
forces
\[
p\mid z(x_2).
\]

But then the reduction of \(z\) modulo \(p\) satisfies
\[
z(x_2)\equiv0\pmod p,
\]
contradicting
\[
f(x_2)=1.
\]

Thus
\[
H^1(W_N,A_k(\chi_k))
\to
H^1(W_N,\mathbf F_p)
\]
is **not** surjective.

Hence
\[
\boxed{
\mathsf K_k(W_N,\chi_k)\text{ is false}.
}
\]

This is a stronger obstruction than merely exhibiting a false candidate: the canonical candidate itself fails at the endpoint window.

## 5. Minimality theorem

Combining the two cases:

### Case 1: \(m<N\)

\[
\chi_k\notin\operatorname{Hom}(W_m,U_{1,k}),
\]
so \(W_m\) cannot even represent the canonical orientation modulo \(p^k\).

### Case 2: \(m=N\)

\[
\chi_k\text{ factors through }W_N,
\]
but
\[
\mathsf K_k(W_N,\chi_k)
\]
fails.

Therefore no \(m\le N\) can support the finite Kummer recognition theorem.

Since the already-proved theorem gives recognition at \(W_{N+1}\), we obtain:

\[
\boxed{
n_{\mathrm{selector}}(k)
=
p^{k-1}+1
=
3^{k-1}+1
}
\]

for the fixed rank-four, \(q=3\) pro-3 Demuškin group.

## 6. Why this closes the previous logical gap

The earlier affine-sharpness argument only proved

\[
\text{all affine cocycles factor through }W_{N+1},
\]
and showed that this threshold is sharp for the full affine category.

That did not by itself imply selector minimality.

The new argument is independent of that implication.

It identifies the exact obstruction at the boundary:

\[
W_N:
\quad
x_2\text{ has order }p^{k-1},
\qquad
\chi_k(x_2)=(1-p)^{-1},
\]
and the cyclic crossed-cocycle equation forces every \(A_k(\chi_k)\)-valued cocycle to reduce trivially on \(x_2\).

So the finite Kummer lifting condition itself detects the missing layer.

The endpoint \(+1\) is therefore not an artifact of the affine proof.

## 7. Scope

The proof above is fully closed for the project's fixed group
\[
p=3,\quad q=3,\quad d=4.
\]

A useful extension is immediate for standard odd-p Demuškin groups with
\[
q=p^f
\]
whenever
\[
f<k.
\]

Indeed
\[
\chi(x_2)=(1-p^f)^{-1},
\]
and LTE gives
\[
v_p\left(
\frac{\chi(x_2)^{p^{k-1}}-1}
{\chi(x_2)-1}
\right)
=
k-1.
\]

Thus the same endpoint obstruction works whenever the canonical orientation is nontrivial at level \(p^k\).

If \(f\ge k\), the canonical orientation is trivial modulo \(p^k\), so this particular endpoint obstruction disappears; uniform minimality over all \(q\) is a separate question.
