# HARD ATTACK 40 — RANK-ONE COEFFICIENT / SPECTRAL-BLINDNESS AUDIT
## 2026-09-20

### Purpose

Hard Attack 39 showed that full coefficient-category completeness is tautological, while completeness of the actual Kummer family A_k(rho)=Z/3^k is an open faithfulness problem.

Hard Attack 40 asks what the restricted family can structurally see, before attempting any computation.

### 1. Equivariance is a scalar specialization

Fix rho:Q_k -> U_k and A=A_k(rho).

For a Q_k-equivariant map phi:M_k -> A,
phi(gm)=rho(g)phi(m).

Hence phi annihilates the twisted relation submodule generated by
gm-rho(g)m.

Define the scalar specialization / twisted coinvariant module
M_{k,rho}
=
M_k / <gm-rho(g)m : g in Q_k, m in M_k>.

Then
Hom_{Q_k}(M_k,A_k(rho))
is naturally identified with the corresponding Z/3^k-linear dual of M_{k,rho} (with the usual finite-module dual convention).

Thus the Kummer profile does not probe arbitrary maps out of M_k. It probes only the one-dimensional scalar-character specializations of the Q_k-module M_k.

### 2. Consequence for the extension class

The restricted push-forward profile of e_k therefore factors through the family of specialized observations
rho |-> e_k under
M_k -> M_{k,rho} -> A_k(rho).

This gives a structural interpretation of the kernel K_k from Hard Attack 39:

K_k is the part of H^2(Q_k,M_k) invisible after every scalar-character specialization occurring in the allowed Kummer family.

This is stronger than merely saying that K_k "might" be nonzero. It identifies exactly what kind of information would be lost if it is nonzero.

### 3. Important limitation

This does NOT prove K_k != 0 for the actual Demushkin extension.

A finite 3-group has very restricted simple mod-3 representation theory, and the special family of scalar p-adic characters may interact unusually well with the particular extension class e_k. Therefore a generic representation-theoretic no-go cannot be promoted to the Demushkin case without an additional theorem.

So the correct classification is:

- restricted profile factors through scalar-character specializations: **PASS / CLOSED**;
- restricted profile is automatically faithful on the Demushkin extension class: **OPEN**;
- generic category-independent non-faithfulness: **NOT CLAIMED**.

### 4. Stronger reformulation of the selector problem

The PD²-independent selector problem can now be stated without any ambiguity:

For the specific e_k, determine whether the scalar-character specialization function
rho |-> |coker[
Hom_{Z/3^k}(M_{k,rho},A_k(rho))
 -> H^2(Q_k,A_k(rho))
]|
has a unique maximizer.

The remaining issue is not "recover all of e_k".

It is whether the scalar-character spectral data of this one extension class has a unique orientation signature.

### 5. New obstruction test before computation

Any proposed proof that uses the entire Q_k-module M_k must first exhibit a factorization through the scalar-specialization family.

Conversely, any proposed proof of selector uniqueness that genuinely needs a higher-dimensional Q_k-coefficient module is outside the present Kummer carrier and constitutes a new carrier category.

This gives a clean diagnostic:

- scalar-specialization proof succeeds -> PD²-independent Kummer selector remains viable;
- scalar-specialization proof fails because essential information lives in higher-dimensional coefficients -> present carrier is insufficient, yielding a precise negative boundary rather than a failed computation.

### 6. Fox comparison remains secondary

The coordinate Fox row can now be interpreted as a possible explicit calculation of one of these scalar-character push-forwards.

The correct order remains:
finite extension cocycle -> push-forward -> scalar coefficient specialization -> H^2 class -> coordinate Fox formula.

A Fox row obtained independently cannot be used to assert this factorization without proof.

### 7. Classification

- scalar-character factorization of the restricted Kummer profile: **PASS / CLOSED**;
- scalar-family faithfulness for e_k: **OPEN / DECISIVE**;
- unique scalar-character maximizer without PD²: **OPEN / DECISIVE**;

### Bottom line

Hard Attack 40 does not produce a selector yet, but it materially narrows the search space.

The actual finite carrier is now understood as a scalar-character spectroscopy of the extension class e_k.

The next meaningful attack is therefore to determine whether the Demushkin e_k has a special scalar-character visibility property strong enough to force a unique maximizer. No broad scan is authorized until that property is formulated as a theorem-level statement.
