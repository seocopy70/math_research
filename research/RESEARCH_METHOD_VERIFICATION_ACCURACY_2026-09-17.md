# 수학연구 검증·정확성 원칙 — 2026-09-17

## 배경
A3-4가 복잡해지면서, 이미 올바르게 계산된 부분을 후속 구현에서 잘못 다루거나 구현상의 오류를 새로운 수학적 성질로 오인할 위험이 실제로 발생했다. 대표적으로 `End_H(W)=45`라는 잘못된 결과는 nullspace 행렬의 열/행 방향을 잘못 순회한 구현 오류였고, Krylov rank 실패는 W를 ambient 부분공간처럼 취급하여 quotient action을 잘못 구성한 데서 비롯되었다.

따라서 연구의 핵심 기준은 계산량이나 진행 속도보다 **수학적 정확성**으로 둔다.

## 핵심 원칙

1. **정확성이 최우선이다.**
   시행착오 자체를 완전히 제거하는 것은 현실적으로 어렵다. 대신 잘못된 계산이 수학적 사실로 굳어지는 것을 막는 것을 우선한다.

2. **검증의 개수보다 독립성이 중요하다.**
   같은 가정·같은 구현 구조를 반복해서 계산하는 것은 진정한 독립 검증이 아니다. 핵심 결과는 가능하면 다른 관점 또는 다른 계산 경로에서 검증한다.

3. **검증을 무한히 중첩하지 않는다.**
   계산 → 검증 → 검증의 검증 → 검증의 검증의 검증으로 이어지는 구조는 피한다. 충분히 독립적인 증거가 확보되고 사전에 정한 종료 조건을 만족하면 결과를 확정하고 다음 수학 문제로 넘어간다.

4. **검증 강도는 위험도에 따라 차등화한다.**
   - 핵심 수학적 주장: 독립적·다관점 검증을 강하게 적용한다.
   - 이미 검증된 계산 기반/인프라: 기본 sanity check를 유지하되 매번 무겁게 재검증하지 않는다.
   - 단순 파생 계산: 최소한의 검증으로 충분하다.

5. **검증 코드는 원래 계산보다 가능한 한 단순하게 유지한다.**
   검증 코드 자체가 복잡한 또 하나의 연구 계산 프로그램이 되면 동일한 오류가 복제되거나 검증의 검증이 필요해진다.

6. **이상한 계산 결과를 곧바로 새로운 수학적 현상으로 해석하지 않는다.**
   먼저 정의, 공간, 좌표계, 표현 방향, quotient/ambient 구분, 행렬 배열 방향 및 객체의 동일성을 확인한다.

7. **핵심 객체와 관계는 provenance를 기록한다.**
   각 중요한 객체에 대해 정의, 기원, 의존성, 검증 상태, 아직 증명되지 않은 동일성/관계를 기록한다. 특히 `K_N = ker N`과 `I = W ∩ Wd`처럼 차원만 같다고 동일하다고 볼 수 없는 객체는 별도로 취급한다.

8. **검증이 끝난 결과는 고정하고 재사용한다.**
   원칙적으로 복잡한 계산은 한 번 정확하게 수행하고, 독립 검증을 거친 뒤 artifact로 고정하여 후속 단계가 같은 계산을 불필요하게 재구현하지 않도록 한다.

## 현재 A3-4에 적용하는 종료 기준의 예

`N → ker N → I` 관계에 대해서는 다음을 확인하면 추가적인 '검증의 검증'을 계속 만들지 않는다.

- 독립적인 N 재구성
- `N^2 = 0`, `rank N = 10`, `dim ker N = 35`
- 독립적인 `I = W ∩ Wd` 계산
- 두 35차원 부분공간의 실제 동일성 확인

이 조건들이 충족되면 결과를 artifact로 고정하고 tau 및 이후 연구로 진행한다.

## 연구 철학

> 시행착오를 0으로 만드는 것이 목표가 아니다. 시행착오가 발생하더라도 그것이 잘못된 수학적 결론으로 굳어지지 않도록 하는 것이 목표다.
>
> **핵심 주장에는 강하게 검증하고, 검증된 기반에는 가볍게, 단순 파생 계산에는 최소한으로 적용한다.**
>
> 최종 목표는 '계산을 많이 했다'가 아니라 **수학적으로 믿을 수 있는 결과를 남기는 것**이다.
