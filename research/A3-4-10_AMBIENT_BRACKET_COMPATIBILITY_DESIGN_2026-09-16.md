# A3-4-10 — Ambient bracket compatibility

Date: 2026-09-16

## 1. Purpose

A3-4-9 established that the two 45-dimensional Sp4(F3)-modules

- W45, generated by T = [[[X3,X4],X1],X1], and
- Wd, generated by d = [X1^[3],X2],

have equivalent extensions of the common 35-dimensional submodule
K = ker(N), with an H-isomorphism X: W45 -> Wd fixing K pointwise.

The next question is whether this equivalence survives the ambient free-Lie-algebra embedding. Abstract module/extension equivalence is weaker than compatibility with the Lie bracket in the ambient algebra.

## 2. Test

For each degree-1 generator X_g (g=1,2,3,4), compare

  X([w, X_g]) = [X(w), X_g]

for every w in W45, using the verified A3-4-9 intertwiner X.

The computation is performed in the associative degree-5 word space (dimension 4^5 = 1024). Since the free Lie algebra embeds in its tensor/associative algebra, equality of the associative expansions is an exact equality test for the Lie brackets.

We also compute the rank of the stacked bracket discrepancy as a quantitative obstruction if compatibility fails.

## 3. Scope

This experiment does not assume that q-sensitive information is absent from higher restricted structure. It tests only whether the already-established A3-4-9 equivalence is compatible with the first ambient bracket operation W -> L5.

Possible outcomes:

1. Compatible: the 45D extension equivalence also respects this ambient bracket layer, so the next target should be restricted p-map / higher filtration operations.
2. Not compatible: the q-sensitive distinction is already visible in the ambient embedding/bracket structure, giving a concrete direction for an intrinsic invariant.
